## Background (why)
Production (Vercel, https://app.sendkiss.online) has none of BETTER_AUTH_URL / BETTER_AUTH_SECRET / GROK_AUTH_* set. `src/lib/auth/server.ts` therefore falls back to the shared Grok preview client `grok_preview`, a dynamic baseURL whose fallback is `http://localhost:8080`, and a random per-process secret. Result: Google/X send `redirect_uri=http://localhost:8080/api/auth/oauth2/callback/grok-google` to auth.grok.me, which rejects it ("Invalid redirect URI"). We are switching to our own Google and X OAuth apps via Better Auth `socialProviders`.
